## חוקי הברזל
1. עורכים רק את קובץ ה-CSS שלכן ואת האזור שלכן ב-index.html (בין שורות ה-START וה-END).
2. לא מוחקים ולא משנים את שורות ההערה START/END.
3. כל מחלקה מתחילה בקידומת של החלק שלכן. אין סלקטורים על תגיות חשופות (div, a, ul...).
4. לא נוגעים ב-css/base.css.
5. פחות מ-30 דקות בלי commit - זה יותר מדי.
6. לא מעתיקות תמונות, כתבות או פרסומות מהאתר המקורי. הטקסטים ב-docs/CONTENT.md.
